# Семантический анализатор для языка Funny (HW3)

## Описание проекта

Реализация семантического анализатора для строгого подмножества языка Funny. Анализатор обходит построенное парсером абстрактное синтаксическое дерево (AST), проверяет правила типизации, области видимости, соответствие сигнатур при вызовах функций и собирает все ошибки без прерывания работы. На выходе строится аннотированное AST (каждый узел выражения получает вычисленный тип) для последующей кодогенерации. 

**Ключевые особенности версии:**
- Вывод типов локальных переменных по первому присваиванию.
- Строгая проверка логических типов в условиях `if` и `while`.
- Запрет использования имени функции в качестве переменной.
- Изолированный вывод чистого AST в `System.out` и диагностических сообщений в `System.err` для удобной генерации snapshot-файлов.

## Требования

- Java 17+
- Утилита `make` (для автоматизированной сборки)
- Библиотека Java-CUP (`lib/java-cup-11b.jar`) — *включена в репозиторий*
- Библиотека JFlex (`lib/jflex.jar`) — *включена в репозиторий*

## Структура проекта

- `Makefile` — скрипт автоматизированной сборки проекта и очистки скомпилированных файлов.
- `src/semantic/` — классы семантического анализатора (`SemanticAnalyzer`, `Scope`, `SymbolInfo`), реализующие проверки и таблицу символов.
- `src/ast/` — классы узлов абстрактного синтаксического дерева (AST), расширенные полем `exprType` для хранения аннотаций типов.
- `src/lexer/lexer.jflex` — спецификация лексера JFlex.
- `src/parser/parser.cup` — грамматика и правила парсера CUP.
- `src/Main.java` — точка входа для запуска всего пайплайна (лексер -> парсер -> семантический анализ -> генерация/сверка AST).
- `tests/` — директория с позитивными, негативными тестами и их эталонными `.ast` снимками (включая тесты строгой грамматики преподавателя).

## Поддерживаемый синтаксис Funny
Компилятор поддерживает строгую спецификацию языка:
- **Объявление функций** без обязательного ключевого слова `function` (например, `main(x: int, y: int)`).
- **Параметры** задаются в формате `id : type`.
- **Множественные возвращаемые значения** через ключевое слово `returns` с именованными параметрами (например, `returns r: int, p: int`).
- **Объявления** локальных переменных через блок uses (с поддержкой вывода типов по первому присваиванию, если тип не указан явно)
- **Условные конструкции** `if` с опциональной веткой `else`.

## Сборка и запуск

1. **Очистка проекта**:
```
make clean
```

2. **Полная компиляция** (генерирует лексер, парсер и компилирует все `.java` файлы):

```bash
make compile
```

3. **Генерация эталонного AST (snapshot)** для нового теста:

```bash
java -cp "lib/java-cup-11b.jar:src" Main tests/test_positive.txt > tests/test_positive.ast
```

4. **Запуск тестов и сверка с эталоном**:

```bash
java -cp "lib/java-cup-11b.jar:src" Main tests/test_positive.txt tests/test_positive.ast

java -cp "lib/java-cup-11b.jar:src" Main tests/test_negative.txt tests/test_negative.ast
```
