# Семантический анализатор для языка Funny

## Описание проекта

Реализация семантического анализатора для подмножества языка Funny. Анализатор обходит построенное парсером абстрактное синтаксическое дерево (AST), проверяет правила типизации, области видимости, соответствие сигнатур при вызовах функций и собирает все ошибки без прерывания работы. На выходе строится аннотированное AST (каждый узел выражения получает вычисленный тип) для последующей кодогенерации. Реализован бонус: вывод типов локальных переменных по первому присваиванию.

## Требования

* Java 17+
* Библиотека Java-CUP (`lib/java-cup-11b.jar`)
* Библиотека JFlex (`lib/jflex.jar`)

## Структура проекта

* `src/semantic/` — классы семантического анализатора (`SemanticAnalyzer`, `Scope`, `SymbolInfo`), реализующие проверки и таблицу символов.
* `src/ast/` — классы узлов абстрактного синтаксического дерева (AST), расширенные полем `exprType` для хранения аннотаций типов.
* `src/lexer/lexer.jflex` — спецификация лексера JFlex.
* `src/parser/parser.cup` — грамматика и правила парсера CUP с поддержкой типов, параметров и вызовов функций.
* `src/Main.java` — точка входа для запуска всего пайплайна (лексер -> парсер -> семантический анализ -> сверка AST).
* `tests/` — директория с позитивными и негативными тестами и их эталонными `.ast` снимками.

## Сборка и запуск

1. Генерация лексера и парсера:
```bash
java -jar lib/jflex.jar -d src/lexer src/lexer/lexer.jflex
java -cp "lib/java-cup-11b.jar" java_cup.Main -destdir src/parser -parser FunnyParser src/parser/parser.cup

```


2. Компиляция проекта:
```bash
javac -cp "lib/java-cup-11b.jar:src" src/ast/*.java src/semantic/*.java src/lexer/*.java src/parser/*.java src/Main.java

```


3. Запуск позитивного теста (проверка корректных типов):
```bash
java -cp "lib/java-cup-11b.jar:src" Main tests/test_positive.txt tests/test_positive.ast

```


4. Запуск негативного теста (отлов семантических ошибок, неизвестных имен и неверных аргументов):
```bash
java -cp "lib/java-cup-11b.jar:src" Main tests/test_negative.txt tests/test_negative.ast

```
