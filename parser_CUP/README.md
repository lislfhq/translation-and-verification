# Parser для языка Funny

## Описание проекта
Реализация LR(1) синтаксического анализатора (с использованием генератора CUP) и интегрированного лексера (на базе JFlex) для подмножества языка Funny. Парсер строит абстрактное синтаксическое дерево (AST) с поддержкой позиций токенов, приоритетов операторов и обработки синтаксических ошибок.

## Требования
* Java 17+
* Make
* Библиотека Java-CUP (`lib/java-cup-11b.jar`)

## Структура проекта
* `src/lexer/lexer.jflex` — спецификация лексера JFlex.
* `src/parser/parser.cup` — грамматика и правила парсера CUP.
* `src/ast/` — классы узлов абстрактного синтаксического дерева (AST) с поддержкой рекурсивного метода `dump()`.
* `src/Main.java` — точка входа для запуска парсера на файле с исходным кодом.
* `test_funny.txt` — пример корректной программы на языке Funny.

## Сборка и запуск

1. Сборка проекта и запуск позитивного теста:
   ```bash
   make test

2. Запуск негативного теста (отлов ошибок):
   ```bash
   make test-neg
   
3. Запустить все тесты:
   ```bash
   make test-all
   
4. Очистка сгенерированных файлов и папки сборки:
    ```bash
   make clean
