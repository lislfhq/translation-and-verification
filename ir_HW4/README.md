# Промежуточное представление (IR), CFG, локальные оптимизации и распределение регистров (HW4)

## Описание проекта

Реализация компилятора языка Funny поверх аннотированного AST из HW3. Модуль строит трёхадресный код (Three-Address Code, TAC), разбивает его на граф потока управления (CFG) из базовых блоков, применяет набор отключаемых локальных оптимизаций, выполняет обратный анализ живости переменных (`liveIn` / `liveOut`), строит граф конфликтов и выполняет жадную раскраску для назначения слотов локальных переменных JVM.

Для верификации корректности оптимизаций встроен интерпретатор IR (`IRInterpreter`), сравнивающий результаты выполнения до и после оптимизаций на одинаковых входных аргументах.

## Формат промежуточного представления (IR) и API для кодогенерации JVM

### Операнды (`ir.Operand`)
* `CONST` — целочисленные и булевы константы (`0` для `false`, `1` для `true`, аналогично представлению на стеке операндов JVM).
* `VAR` — именованные параметры/переменные и временные регистры `t0, t1, ...` с типом `ast.Type` (`INT`, `BOOL`, `INT_ARRAY`, `BOOL_ARRAY`).
* `LABEL` — символьные метки переходов (`L_else_0`, `L_while_1`, ...).

### Инструкции (`ir.IRInstruction`)
| OpCode | Текстовый формат | Семантика и соответствие JVM |
| :--- | :--- | :--- |
| `ASSIGN` | `dst = src1` | Копирование значения (`iload` / `istore` / `aload` / `astore`) |
| `BINOP` | `dst = src1 op src2` | Бинарная операция (`+`, `-`, `*`, `/`, `%`, `==`, `!=`, `<`, `<=`, `>`, `>=`, `and`, `or`) |
| `UNOP` | `dst = op src1` | Унарная операция (`-` -> `ineg`, `not` -> `ixor 1`) |
| `LOAD_ARR` | `dst = src1[src2]` | Чтение элемента массива (`iaload` / `baload`) |
| `STORE_ARR` | `dst[src1] = src2` | Запись элемента массива (`iastore` / `bastore`) |
| `NEW_ARR` | `dst = new_array(src1)` | Выделение локального массива (`newarray int`) |
| `LENGTH` | `dst = length(src1)` | Длина массива (`arraylength`) |
| `CALL` | `d0, d1 = call f(a0, ...)` | Вызов функции с поддержкой кортежных результатов (`invokestatic`) |
| `LABEL` | `L0:` | Метка цели перехода |
| `GOTO` | `goto L0` | Безусловный переход (`goto`) |
| `IF_FALSE` | `if_false src1 goto L0` | Условный переход при `0` (`ifeq`) |
| `RETURN` | `return r0, r1` | Возврат результатов функции (`ireturn` / упаковка кортежа) |

### API для трансляции в байт-код JVM (проект)
* `List<IRFunction> funcs = new IRGenerator().generate(annotatedAst);` — генерация IR из AST.
* `new LocalOptimizer(config).optimize(fn);` — оптимизация базовых блоков и пересборка CFG (`fn.cfg`).
* `InterferenceGraph ig = InterferenceGraph.build(fn);` — построение графа конфликтов по `liveIn`/`liveOut`.
* `GreedyColoring coloring = GreedyColoring.color(ig);` — отображение `varName -> slotIndex` (`r0, r1, ...`), готовое для маппинга в локальные переменные метода JVM.

## Реализованные оптимизации и CLI-флаги

Все проходы работают в пределах базовых блоков итеративно до неподвижной точки и управляются через `opt.OptimizationConfig` или флаги командной строки:
* `--no-opt` — отключить все оптимизации;
* `--no-const` — отключить распространение и свёртку констант;
* `--no-alg` — отключить алгебраические упрощения (`x + 0`, `x * 1`, `x * 0`, `x - x`, `x and true` и др.);
* `--no-cse` — отключить локальное устранение общих подвыражений (CSE);
* `--no-dce` — отключить локальное удаление мёртвого кода (DCE с учётом `liveOut` блока);
* `--dot-cfg` — вывести CFG в формате Graphviz DOT;
* `--dot-ig` — вывести граф конфликтов в формате Graphviz DOT;
* `--run a,b,...` — выполнить функцию на интерпретаторе IR до и после оптимизаций и сверить результаты;
* `--ast-only` — вывести только аннотированное AST (совместимость с HW3).

## Сборка и запуск

1. **Очистка и компиляция:**
```bash
make clean && make compile
```

2. **Запуск всех автотестов (AST, IR, оптимизации, раскраска, интерпретатор, CLI-флаги):**
```bash
make test
```

**Пример запуска на вычислительном фрагменте с проверкой выполнения:**
```bash
java -cp "lib/java-cup-11b.jar:src" Main tests/test_ir_expr.txt --run 7
```

**Вывод CFG и графа конфликтов в формате Graphviz DOT:**
```bash
java -cp "lib/java-cup-11b.jar:src" Main tests/test_ir_branch.txt --dot-cfg --dot-ig
```
